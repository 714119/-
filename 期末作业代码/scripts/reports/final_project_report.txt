
网球比赛预测项目 - 期末作业报告
============================================================

📊 项目概述
项目目标：基于深度学习的网球比赛势头分析与预测
数据来源：2023年温网31场比赛，共7,253个数据点
任务类型：二分类（预测下一分获胜方）
最佳模型：ensemble

🎯 关键发现
1. 发球方优势显著：发球方胜率约62%
2. 机器学习有效：最佳模型准确率达到63.9%
3. 特征工程关键：发球方特征最重要（72.35%重要性）
4. 集成学习优势：集成模型达到63.9%准确率

🏆 模型表现排名
 1. ensemble            : 0.639 (vs随机: +0.128) (vs发球方: +0.024)
 2. xgboost             : 0.637 (vs随机: +0.126) (vs发球方: +0.022)
 3. 随机森林基线              : 0.636 (vs随机: +0.125) (vs发球方: +0.021)
 4. gradient_boosting   : 0.635 (vs随机: +0.124) (vs发球方: +0.020)
 5. random_forest       : 0.634 (vs随机: +0.123) (vs发球方: +0.019)
 6. lightgbm            : 0.632 (vs随机: +0.121) (vs发球方: +0.017)
 7. neural_network      : 0.624 (vs随机: +0.113) (vs发球方: +0.009)
 8. 预测发球方赢              : 0.615 (vs随机: +0.104)
 9. logistic_regression : 0.610 (vs随机: +0.099)
10. LSTM模型              : 0.606 (vs随机: +0.095)

📈 性能指标
- 最佳准确率: 0.639
- 相对于随机基准提升: +0.128 (+25.1%)
- 相对于发球方基线提升: +0.024 (+4.0%)
- AUC分数: 0.6631

💡 技术收获
1. 数据处理：识别并修复数据泄露问题（next_point_victor特征泄露）
2. 特征工程：创建发球方、比分、势头等有效特征
3. 模型比较：测试了LSTM、随机森林、集成学习等多种模型
4. 评估验证：使用AUC、准确率等多维度评估指标
5. 集成学习：简单平均集成显著提升模型表现

🔍 特征分析
1. 发球方特征 (72.35%) - 最重要的预测因素
2. 是否局点 (15.85%) - 关键分识别能力
3. 比分差值 (11.79%) - 当前比分状态
4. 其他特征：历史胜率、发球质量等
